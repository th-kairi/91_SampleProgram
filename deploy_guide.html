実習・本番公開ガイド（Amazon Linux 2023版）

Webアプリケーション公開実践マニュアル

手元のパソコンで作ったWebアプリケーション（Django / Flask / Servlet）を、AWS EC2（無料利用枠：Amazon Linux 2023）に設置し、インターネットに本番公開するまでの全手順を解説します。

📋 目次ナビゲーション:
全体の仕組み ステップ1: EC2サーバーの作成 ステップ2: ログイン（Tera Term / PowerShell） ステップ3: ソフトウェアの準備 ステップ4: アプリの起動 ステップ5: Nginx受付係の設定 ステップ6: ブラウザ表示確認 困ったときは

全体の流れ（何をするのか？）

手元のパソコンの電源を切っても24時間アクセスできるように、クラウド（AWS EC2）上に Amazon Linux 2023 サーバーを立ち上げて公開します。

通信の流れ：
ブラウザ（世界中） ➡ ポート80でEC2にアクセス ➡ Nginx（受付係） が自動で各アプリ（Django:8000 / Flask:5000 / Servlet:8080）へ振り分け！

1 ステップ 1: AWSでサーバー（EC2）を作ろう

AWSマネジメントコンソールから、Amazon Linux 2023 が入った仮想コンピューターを1台立ち上げます。

1-1. AWSにログインして東京リージョンを確認する

  1. ブラウザでAWSにサインインします。
  2. 画面右上の地域が「東京（ap-northeast-1）」になっていることを確認します。
  3. 上部の検索バーに EC2 と入力し、一覧の「EC2」をクリックします。
  4. 左側メニューの「インスタンス」を開き、オレンジ色の「インスタンスを起動」ボタンをクリックします。

1-2. サーバーの基本設定

項目名選ぶ値理由・解説
名前とタグmy-web-server など自由サーバーを識別するための名前です。
OSイメージ (AMI)Amazon Linux
(Amazon Linux 2023 AMI)		AWS公式の高速・安全なLinuxOSです。無料枠対象です。
インスタンスタイプt2.micro または t3.micro「無料利用枠の対象」と書かれたものを選びます。

1-3. キーペア（サーバーの鍵）を作る

サーバーに遠隔ログインするための「秘密鍵」を発行します。紛失すると二度とサーバーに入れなくなるため大切に保管してください。

  1. 「キーペア (ログイン)」項目で、右側の「新しいキーペアの作成」をクリックします。
  2. キーペア名に my-key など半角英数で入力します。
  3. キーペアのタイプは RSA、ファイル形式は .pem を選びます。（Tera Term も PowerShell も両方 .pem で接続できます）
  4. 「キーペアを作成」を押すと、パソコンに my-key.pem がダウンロードされます。安全なフォルダに保存してください。

1-4. ネットワーク設定（ファイアウォール）

  1. 「ネットワーク設定」の右上の「編集」をクリックします。
  2. 「セキュリティグループを作成」を選び、以下の3つのルールが揃っていることを確認します。
種類ポート番号ソース（接続元）役割
SSH22自分のIP または 0.0.0.0/0自分のパソコンから遠隔操作するための通り道
HTTP80任意の場所 (0.0.0.0/0)ブラウザでWebサイトを見るための通り道
HTTPS443任意の場所 (0.0.0.0/0)暗号化された安全なWeb通信のための通り道
注意: HTTP（80番ポート）が開いていないと、あとでブラウザからサイトを開くことができません。必ず「インターネットからの HTTP トラフィックを許可する」にチェックを入れてください。

1-5. インスタンスの起動

画面右下のオレンジ色の「インスタンスを起動」ボタンをクリックします。約1〜2分でステータスが「実行中」になります。

2 ステップ 2: 自分のパソコンからサーバーにログインしよう

EC2管理画面で、作成したサーバーの 「パブリック IPv4 アドレス」（例: 54.238.123.45）をコピーしておきます。
お使いのツールに合わせて、【方法A】または【方法B】のいずれかで接続します。

【方法 A】Tera Term でログインする場合

  1. Tera Term を起動します。
  2. 「新しい接続」画面で以下を入力して「OK」を押します：
    • ホスト: コピーしたパブリックIPv4アドレス
    • TCPポート: 22、サービス: SSH
  3. 初回警告が出たら「続行」をクリックします。
  4. 「SSH認証」画面で以下を入力します：
    • ユーザ名: ec2-user（※Amazon Linuxの標準ユーザー）
    • パスフレーズ: （空欄のままでOK）
    • 「RSA/DSA/ECDSA/ED25519鍵を使う」を選び、「秘密鍵」ボタンから my-key.pem を指定
  5. 画面に [ec2-user@ip-... ~]$ と出ればログイン成功です！

【方法 B】PowerShell でログインする場合

① 鍵（.pem）を保存したフォルダに移動します（例: ダウンロードフォルダ）：

PowerShell
cd C:\Users\admin\Downloads

② 以下のSSHコマンドを実行します（※IPと鍵名はご自身のものに置き換えてください）：

SSH接続コマンド
ssh -i my-key.pem ec2-user@54.238.123.45
初回のみ yes と入力して Enter を押すと、[ec2-user@ip-... ~]$ に切り替わりログイン完了です！

3 ステップ 3: サーバーに必要な道具を入れよう

3-1. サーバーの更新とソフトウェア導入（dnf）

Amazon Linux 2023 では dnf コマンドで一括インストールします：

Bash
sudo dnf update -y
sudo dnf install -y git python3-pip python3-devel openjdk-17-jdk nginx postgresql16-server postgresql16 wget unzip

3-2. PostgreSQL（データベース）の初期化と起動

Bash
sudo postgresql-setup --initdb
sudo systemctl enable --now postgresql

3-3. プログラムをサーバーに配置する

GitHubから直接クローンして配置します：

Bash
cd ~
git clone https://github.com/th-kairi/91_SampleProgram.git exshop
※Tera Termをお使いの場合は、ローカルのZIPファイルをTera Termの画面にドラッグ＆ドロップして「SCP」をクリックするだけで直接転送することも可能です。

4 ステップ 4: アプリケーションを動かそう

動かしたいエディションの手順を実行します。（3つ全部同時に動かすことも可能です）

コース A: Django版（ポート 8000）

Bash
cd ~/exshop/01_Django
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt gunicorn
python manage.py migrate
python manage.py collectstatic --noinput

sudo bash -c 'cat < /etc/systemd/system/django_exshop.service
[Unit]
Description=Gunicorn instance for Django exShop
After=network.target

[Service]
User=ec2-user
WorkingDirectory=/home/ec2-user/exshop/01_Django
Environment="PATH=/home/ec2-user/exshop/01_Django/venv/bin"
ExecStart=/home/ec2-user/exshop/01_Django/venv/bin/gunicorn --workers 3 --bind 127.0.0.1:8000 exShop.wsgi:application

[Install]
WantedBy=multi-user.target
EOF'

sudo systemctl daemon-reload
sudo systemctl enable --now django_exshop

コース B: Flask版（ポート 5000）

Bash
cd ~/exshop/02_Flask
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt gunicorn

sudo bash -c 'cat < /etc/systemd/system/flask_exshop.service
[Unit]
Description=Gunicorn instance for Flask exShop Nordic
After=network.target

[Service]
User=ec2-user
WorkingDirectory=/home/ec2-user/exshop/02_Flask
Environment="PATH=/home/ec2-user/exshop/02_Flask/venv/bin"
ExecStart=/home/ec2-user/exshop/02_Flask/venv/bin/gunicorn --workers 3 --bind 127.0.0.1:5000 run:app

[Install]
WantedBy=multi-user.target
EOF'

sudo systemctl daemon-reload
sudo systemctl enable --now flask_exshop

コース C: Servlet / JSP版（Tomcat 10 + PostgreSQL）

① Tomcat 10 のインストール：

Bash
cd /opt
sudo wget https://archive.apache.org/dist/tomcat/tomcat-10/v10.1.30/bin/apache-tomcat-10.1.30.tar.gz
sudo tar xzf apache-tomcat-10.1.30.tar.gz
sudo mv apache-tomcat-10.1.30 tomcat10
sudo chown -R ec2-user:ec2-user /opt/tomcat10
chmod +x /opt/tomcat10/bin/*.sh

② PostgreSQL にデータベースとデータを準備：

Bash
sudo -u postgres psql -c "CREATE USER exshop WITH PASSWORD 'exshop_pass';"
sudo -u postgres psql -c "CREATE DATABASE exshop_db OWNER exshop;"

cd ~/exshop/03_Servlet
PGPASSWORD='exshop_pass' psql -U exshop -d exshop_db -h localhost -f sql/schema.sql
PGPASSWORD='exshop_pass' psql -U exshop -d exshop_db -h localhost -f sql/data.sql

③ WARファイルを配置して起動：

Bash
sudo cp ~/exshop/03_Servlet/target/exShop.war /opt/tomcat10/webapps/ROOT.war
/opt/tomcat10/bin/startup.sh

5 ステップ 5: 受付係（Nginx）を設定して公開しよう

外部からの80番ポートへのWebアクセスを受け取り、各アプリへ案内する設定を行います。

Bash
sudo bash -c 'cat < /etc/nginx/conf.d/exshop.conf
server {
    listen 80 default_server;
    server_name _;

    location /static/ {
        alias /home/ec2-user/exshop/01_Django/static/;
    }
    location /media/ {
        alias /home/ec2-user/exshop/01_Django/media/;
    }

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host \$host;
        proxy_set_header X-Real-IP \$remote_addr;
        proxy_set_header X-Forwarded-For \$proxy_add_x_forwarded_for;
    }

    location /flask/ {
        proxy_pass http://127.0.0.1:5000/;
        proxy_set_header Host \$host;
        proxy_set_header X-Real-IP \$remote_addr;
    }

    location /servlet/ {
        proxy_pass http://127.0.0.1:8080/;
        proxy_set_header Host \$host;
        proxy_set_header X-Real-IP \$remote_addr;
    }
}
EOF'

chmod 711 /home/ec2-user
sudo nginx -t
sudo systemctl enable --now nginx
sudo systemctl restart nginx

6 ステップ 6: ブラウザで実際に見てみよう！

これでインターネットへの公開が完了しました！ブラウザを開いて確認しましょう：

  • Django版（ストリート系デザイン）: http://<パブリックIP>/
  • Flask版（北欧ナチュラル系デザイン）: http://<パブリックIP>/flask/
  • Servlet版（ラグジュアリー・シック系デザイン）: http://<パブリックIP>/servlet/

困ったときのトラブルシューティング

Q1. ブラウザで開いても「応答時間が長すぎます」「接続できません」となる

➡ 原因: AWSのセキュリティグループで、HTTP（ポート80）が開いていません。
解決策: AWS管理画面の「EC2」➡「セキュリティグループ」➡「インバウンドルールを編集」で「HTTP / 80 / 0.0.0.0/0」を追加してください。

Q2. 「502 Bad Gateway」というエラー画面が出る

➡ 原因: Nginx（受付係）の奥で動くアプリ（DjangoやFlaskなど）が止まっています。
解決策: sudo systemctl status django_exshop を実行し、赤文字のエラーが出ていないか確認してください。

Q3. 画面は開くが、画像やCSSが崩れて文字だけになる

➡ 原因: Nginxがホームディレクトリ内の静的ファイルにアクセスできていません。
解決策: chmod 711 /home/ec2-user を実行してください。
